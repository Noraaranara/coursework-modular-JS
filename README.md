# Instapro

MVP социальной сети для обмена фотографиями

## Первоначальная оценка

8/10, хороший изначальный код, но пришлось долго разбираться и немного переписывать 

## Фактически затраченное время

Около 60 часов

## Реализованная функциональность

- Мгновенное обновление лайков (без перезагрузки страницы)
- Добавление поста с картинкой и описанием
- Автоматическое обновление списка постов после добавления нового поста
- Валидация формы добавления поста (проверка на пустые поля)
- Проверка авторизации перед выполнением действий (лайк, добавление поста)
- Очистка полей формы после успешного добавления поста
- Вывод сообщений об ошибках при неудачных запросах к API
- Просмотр определённого профиля

## Доп фичи

- анимация на иконке лайка, ощущение живого интерфейса
- Просмотр превью картинки перед публикацией
